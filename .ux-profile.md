# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Linear
- **Notes:** Direction artistique « blueprint » : fond bleu nuit (#0f1a2b), grille fine très discrète, bordures de 1 px, Inter pour le texte, JetBrains Mono pour les repères et étiquettes, accent cyan (#5ad1e8) utilisé avec parcimonie. Tous les réglages visuels sont dans `:root` en haut de `assets/style.css`. Défilement en cartes qui s'empilent (`assets/anim.js`) ; animations discrètes, coupées si « réduire les animations ».

## Banned anti-aesthetics

- Verre dépoli / `backdrop-filter` sans bordure nette — exception : l'en-tête collant (flou + bordure 1 px)
- Pastilles pastel flottantes pour des métadonnées ordinaires
- Dégradés décoratifs arbitraires et bordures néon lumineuses — exception : les petits points lumineux cyan (schémas animés, frise), signature blueprint
- Dégradés radiaux arc-en-ciel sur les boutons d'action
- Illustrations cartoon dans les états vides
- Barres de défilement imbriquées et icônes en trop dans les champs

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** 4,5:1 minimum pour le texte courant, 3:1 pour les grands textes et les bordures utiles
- **Touch / focus:** zones tactiles de 44 × 44 px minimum ; contour de focus visible (2 px cyan)

## Brand tone and microcopy voice

- **Voice:** Opinionated & Direct
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Interface en français, première personne et vouvoiement du visiteur. Boutons commençant par un verbe (« Lire l'étude de cas », « Envoyer le message », « Télécharger mon CV »). Phrases courtes, pas de jargon creux.

## Icon library

- **Library:** Project SVG
- **Package / path:** SVG écrits directement dans les pages (ex. coordonnées de `cv/index.html`)
- **Notes:** Trait de 1,8, sans remplissage, `stroke-linecap: round`, couleur de l'accent. Aucune dépendance, pas d'emoji comme icône.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
