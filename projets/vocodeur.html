Pauvocoder : modifier la hauteur d'une voix sans changer sa durée

Programme Java qui lit un fichier .wav, change sa fréquence par rééchantillonnage, puis lui redonne sa durée d'origine par dilatation temporelle.

Semestre
S1
Année
2024
Équipe
Projet de groupe
Langage
Java
  • Java
  • Traitement du signal
  • Algorithmique

01Le principe

Changer la vitesse de lecture d'un son change aussi sa hauteur. Pour modifier l'une sans l'autre, le programme rééchantillonne d'abord le signal (la hauteur change, la durée aussi), puis le redécoupe en séquences de 100 ms qu'il réassemble pour retrouver la durée d'origine.

02Chaîne de traitement

  1. Lecture .wavStdAudio, 44,1 kHz
  2. Rééchantillonnagechangement de hauteur
  3. Dilatationdurée d'origine
  4. Export .wav+ écho

03Trois versions comparées

  • Découpage simple : les séquences sont recollées bout à bout, ce qui crée des clics aux jointures.
  • Avec recouvrement : les séquences se chevauchent sur 20 ms avec un fondu, ce qui adoucit les raccords.
  • Avec corrélation croisée : dans une fenêtre de 15 ms, le programme cherche le décalage où les deux séquences se ressemblent le plus, pour un raccord quasi inaudible.

S'y ajoutent un effet d'écho et un affichage de la forme d'onde.
